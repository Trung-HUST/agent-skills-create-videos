# /webperf — Measure Before You Optimize

$ARGUMENTS

---

## 🔴 CRITICAL RULES

1. **Load performance-optimization & web-design-guidelines skills**.
2. **Measure First**: Never optimize based on intuition; establish benchmark metrics (LCP, INP, CLS, TTFB).
3. **Analyze**: Check bundle sizes, unnecessary re-renders, unoptimized media, render-blocking scripts, and server bottlenecks.
4. **Verify**: Provide before/after measurements proving quantifiable gain.
